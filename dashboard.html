    The numbers behind this view

    The starting view is regular season only, all seasons, which matches the report. Tick Playoffs to include them. Counts and totals add up players' stats; rates divide the two sums shown in each measure's definition. Player-season rankings treat each player's season as one row, so nothing is a career total.
